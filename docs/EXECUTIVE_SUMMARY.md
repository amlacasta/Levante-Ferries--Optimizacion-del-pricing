# Executive Summary — Proyecto 3

## Levante Ferries — Optimización de Pricing y Revenue Management

Este proyecto desarrolla un sistema analítico completo para apoyar decisiones de pricing en rutas de ferry.

El problema de negocio parte de una realidad sencilla: en transporte marítimo de pasajeros, la capacidad es limitada y una plaza vacía no se recupera una vez que la salida ha zarpado.

Por eso, el pricing debe equilibrar:

- Revenue.
- Ocupación.
- Margen.
- Elasticidad.
- Costes.
- Competencia.
- Capacidad.
- Riesgo.

## Metodología

El proyecto sigue este flujo:

```text
1. Generación de datos sintéticos.
2. Análisis exploratorio de pricing y demanda.
3. Estimación de elasticidad.
4. Cálculo de punto de equilibrio.
5. Modelo predictivo de demanda.
6. Simulación avanzada de escenarios.
7. Recomendador formal de pricing.
8. Dashboard ejecutivo final.
```

## Resultado

El resultado es un sistema que genera recomendaciones por viaje y por ruta:

- Subir precio.
- Aplicar promoción.
- Mantener y monitorizar.
- Revisar margen.
- Revisar capacidad o posición premium.
- Enviar a revisión manual.

Cada recomendación incluye:

- Precio recomendado.
- Cambio de precio.
- Score.
- Confianza.
- Explicación de negocio.

## Mensaje final

El proyecto demuestra cómo pasar de datos a decisiones de pricing explicables.

La idea principal:

> Revenue Management no consiste en vender más caro, sino en vender mejor.
