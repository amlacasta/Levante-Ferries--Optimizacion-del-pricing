# Portfolio Pitch — Proyecto de Optimización de Pricing

## Versión corta

Proyecto de Revenue Management aplicado a transporte marítimo, donde se construye un sistema analítico completo para simular escenarios de precio, estimar demanda, calcular elasticidad, evaluar punto de equilibrio y generar recomendaciones explicables por ruta y viaje.

## Versión para entrevista

Quise construir un proyecto que no se quedara en un dashboard descriptivo. Por eso diseñé un flujo completo: primero generé datos simulados con lógica de negocio, después analicé revenue, ocupación y margen, estimé elasticidad, entrené un modelo de demanda, simulé escenarios de precio y finalmente construí un recomendador explicable.

La idea era mostrar cómo los datos pueden apoyar decisiones reales de pricing, no simplemente crear gráficos.

## Versión LinkedIn

He desarrollado un proyecto completo de Business Analytics aplicado a Revenue Management en rutas de ferry.

El proyecto combina:

- Análisis de demanda.
- Elasticidad precio-demanda.
- Punto de equilibrio.
- Predicción de demanda.
- Simulación de escenarios.
- Recomendador formal de pricing.
- Dashboard ejecutivo.

Todo el proyecto utiliza datos sintéticos para mantener confidencialidad, pero con lógica de negocio realista.

## Mensaje clave

De datos a decisiones de pricing explicables.
