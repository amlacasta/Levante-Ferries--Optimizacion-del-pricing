# GitHub Publication Checklist

## Before publishing

- [ ] Remove any reference to real companies.
- [ ] Use only the name `Levante Ferries`.
- [ ] Confirm all data is synthetic.
- [ ] Make sure notebooks run from top to bottom.
- [ ] Check that paths are relative or clearly documented.
- [ ] Add screenshots to `assets/screenshots/`.
- [ ] Export final HTML dashboard.
- [ ] Export final summaries.
- [ ] Add project description to README.
- [ ] Add limitations and future improvements.
- [ ] Check spelling in notebook titles and markdown.
- [ ] Upload only relevant datasets, not heavy intermediate files.
- [ ] Verify that `.gitignore` excludes models or large files if needed.
